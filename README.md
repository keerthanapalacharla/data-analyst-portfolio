MorphoMama AI – Multimodal Postpartum Rehab
MorphoMama AI is an all-in-one postpartum recovery platform powered by Google Gemini 3.6 Flash. It bridges critical gaps in maternal healthcare by combining empathetic cognitive behavioral therapy (CBT) support with computer vision posture tracking for safe physical recovery.

🌟 Key Features
💬 EPDS CBT Agent: Validates maternal emotional distress, provides personalized cognitive reframing, and recommends tailored grounding or breathing techniques based on input.
🏋️ Posture Coach: Provides real-time exercise feedback for core and pelvic floor rehabilitation (e.g., pelvic tilts, bridges) to prevent diastasis recti. Supports live webcam snapshots and file uploads.
📊 BigQuery Analytics Dashboard: Tracks population-level recovery risk benchmarks and recovery metrics across postpartum weeks.
🛠️ Tech Stack
AI Model: Google Gemini 3.6 Flash / 1.5 Flash (via google-genai SDK)
Frontend UI: Streamlit
Data & Analytics: Python, Pandas, NumPy, BigQuery Data Schema
Computer Vision Tracking: MediaPipe (simulated joint alignment metrics)
